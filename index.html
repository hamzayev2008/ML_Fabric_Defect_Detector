ML_toy_detector

Deep learning visual inspection pipeline (ResNet18) for classifying teddy bears (normal vs. defective) in factory quality control.

Problem & Target User

Target User: Employee that classifies teddy bears (normal or defective) in factory.

Automates visual quality inspection on manufacturing lines, providing immediate classification (Normal vs Defective) with probability confidence.

Limitations

Current Prototype Boundaries:

  • Relatively small dataset and experimental test set (26 samples).
  • Binary classification only (normal vs. defective).
  • Expects single teddy bear image as input.
  • Model classifies overall image status but does not locate exact defect coordinates.
  • Confidence scores require further probability calibration on unseen factory lighting conditions.
