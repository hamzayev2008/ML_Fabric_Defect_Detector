ML Fabric Defect Detector

Deep learning computer vision pipeline (ResNet) for simultaneous fabric material and defect classification in textile quality inspection.

Problem & Target User

Target User: Textile and garment quality inspection staff in manufacturing plants.

Automates multi-task fabric inspection by identifying both the fabric material type (11 classes) and defect classification (11 classes including Normal, Skipped Stitch, Broken Stitch, Stain & Damage, Puckering).

Limitations

Current Prototype Scope & Limitations:

  • Evaluates 11 specific fabric classes and 11 defect classes.
  • Expects single, well-lit image of fabric material.
  • Performs image-level defect classification but does not generate bounding box heatmaps.
  • Needle mark defect class was most challenging (0.91 recall on test set).
