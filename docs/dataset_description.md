## Project

Defected Product Detector

## Dataset Sources

- Google Images
- Roboflow Universe Teddy Bear Dataset

## Data Type

RGB images

## Image Size

Approximately 512×512 pixels

## Classes

- Normal
- Defective

## Goal

Binary image classification.

Input:

One teddy bear image.

Output:

Normal or Defective.

## Challenges

- Different lighting conditions
- Different backgrounds
- Different teddy bear colors
- Different defect types

## Future Improvements

- Increase dataset size
- Improve image quality
- Add more defect categories
