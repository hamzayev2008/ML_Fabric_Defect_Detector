# ML_toy_detector

Проект по машинному обучению для **детекции и классификации дефектов мягких игрушек**
(медведи, куклы, кролики — любой цвет) на фотографиях. Цель — построить точную,
быструю и масштабируемую модель компьютерного зрения, способную отличать игрушки
в нормальном состоянии от дефектных (порванный шов, отсутствующий глаз, пятна,
деформации и т.д.).

## 📊 Текущий статус

**Этап: генерация синтетического датасета.** Обучение модели ещё не начато.

На данный момент в репозитории есть только скрипт `generate_toy_dataset.py`,
который генерирует синтетический датасет изображений для будущего обучения
ML-модели (бинарная классификация `normal` / `defective`, либо основа для
detection-модели).

## 🧠 Как устроена генерация данных

Скрипт использует [Pollinations AI](https://pollinations.ai) (модель `flux`) —
бесплатный сервис генерации изображений без API-ключа, обращаясь к нему через
обычные HTTP-запросы.

Логика:

1. Строится план (`make_plan`) из `N` изображений: половина — исправные игрушки,
   половина — дефектные, вперемешку по типам игрушек и цветам.
2. Для каждой записи собирается текстовый промпт (`build_prompt`) вида
   *"product photo of a {color} {toy}, studio lighting, plain background..."*,
   с добавлением конкретного дефекта для дефектных экземпляров.
3. Изображение скачивается (`fetch_image`) по промпту и seed'у, с ретраями
   при ошибках сети/пустых ответах.
4. Результат сохраняется в папки `dataset/normal/` и `dataset/defective/`,
   а вся разметка — в `dataset/labels.csv`.

### Параметры генерации

| Параметр | Значение |
|---|---|
| Типы игрушек | teddy bear, stuffed rabbit, doll |
| Цвета | 12 вариантов (brown, white, pink, beige, gray, blue, yellow, red, purple, green, cream, black) |
| Типы дефектов | 12 вариантов (порванный шов, отсутствующий глаз/ухо, пятна, деформация и др.) |
| Размер изображений | 512×512 |
| Задержка между запросами | 16 сек (анонимный rate-limit Pollinations) |

## 📁 Структура датасета после запуска

```
dataset/
├── normal/           # изображения исправных игрушек
├── defective/         # изображения игрушек с дефектами
└── labels.csv          # filename, label, toy_type, color, defect_type, prompt
```

## ⚙️ Установка и запуск

```bash
pip install requests pillow

python generate_toy_dataset.py
```

Количество изображений задаётся одной переменной в начале файла:

```python
N = 2   # итоговое число фото (N/2 normal + N/2 defective)
```

Сейчас `N = 2` — тестовое значение для проверки, что пайплайн работает.
Перед реальным сбором датасета его нужно увеличить (с учётом того, что
анонимный лимит Pollinations — примерно 1 запрос / 15 сек, время генерации
растёт линейно).

## ⚠️ Известные ограничения

- Все данные синтетические (сгенерированы AI) — потребуется валидация на
  реальных фото игрушек перед продакшн-использованием модели.
- Анонимный доступ к Pollinations ограничен по скорости, что делает генерацию
  больших датасетов медленной.
- Промпты для дефектов текстовые — визуальная реализация дефекта моделью
  генерации не гарантирована на 100%, возможен шум в разметке.
