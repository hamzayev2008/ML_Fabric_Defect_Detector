## Dataset

The dataset consists of **256 real teddy bear images** collected from publicly available sources.

### Classes

| Class | Images |
|--------|-------:|
| Normal | 133 |
| Defective | 123 |

### Image Characteristics

- Real teddy bear photographs
- Multiple teddy bear colors
- Various backgrounds and lighting conditions
- Different camera angles
- Different defect types

### Defect Examples

- Torn fabric
- Missing eye
- Missing ear
- Damaged stitching
- Visible stuffing
- Other manufacturing defects

### Data Split

The dataset will be divided into:

- Training set
- Validation set
- Test set

using an appropriate train/validation/test ratio.

> The dataset is intended for educational and research purposes.
